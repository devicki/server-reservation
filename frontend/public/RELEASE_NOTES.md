- 의견 목록에 **댓글** 기능 추가
- 의견에 **좋아요 반응** 기능 추가 (토글)

- 헤더를 공통 컴포넌트(`Header`)로 통일

- 네비게이션 링크를 헤더 좌측으로 이동

- **비활성화(잠금):** 계정 잠금 시 **SSH 키 접근도 차단**
- **재활성화(해제):** 계정 해제 시 **SSH 키 접근 허용**
